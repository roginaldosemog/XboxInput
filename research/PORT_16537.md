Status: **pesquisa inicial, nao portado, nenhum XEX de teste disponivel**.

Este arquivo registra a primeira etapa. Para os builds abertos, ferramentas
instaladas e mapeamento offline posteriores, veja [ETAPA_2.md](ETAPA_2.md).
Continua nao existindo um plugin aprovado para instalar no console.

Base upstream: `bloxmaster0811/XboxInput`, commit
`3a7920499a4ef437ea1544f462e247a90b832dca`.
Branch de pesquisa: `research/kernel-16537`.

Objetivo: controle oficial Xbox Series X|S por **cabo USB de dados**, sem
atualizar o kernel nem escrever NAND/eMMC. Bluetooth nao faz parte deste port.
Preservar o trabalho upstream e sua licenca GPL-3.0.

## O que ja esta comprovado por inspecao offline

- O parser e o perfil Microsoft VID 045E / PID 0B12 ja existem em
  `source/controller_backend.cpp`. O perfil real do controle do usuario ainda
  precisa ser confirmado; nao foi conectado ou interrogado nesta pesquisa.
- `XboxInputInitializeThread` recusa builds diferentes de 17559 e 17489.
  A protecao continua intacta: nao foi liberado 16537 artificialmente.
- `initFunctionPointers` resolve 23 exports lexicalmente presentes e tambem
  usa enderecos absolutos. Resolver um ordinal nao prova ABI nem comportamento
  compativel com 16537.
- Uma copia de XAM previamente preservada tem execution version/base version
  2.0.16537.0, 2.437.120 bytes, preferred image base 0x815F0000,
  encryption type 0 e compression type 2.
  SHA-256: `4347993F8EDA067250C5F1EE3CF1CEE2C209296DE217F97FFF13BE643F154E55`.
  Isso identifica metadados do arquivo, nao testa a memoria em execucao.
- O payload PE desse XEX precisa ser descompactado antes de procurar funcoes
  e calcular enderecos virtuais. Offset de arquivo nao e endereco de RAM;
  procurar uma sequencia no XEX compactado nao resolve o port.
- O inventario lexical encontra 33 ocorrencias de constantes 0x8xxxxxxx.
  Nao sao 33 dependencias ativas: inclui mascaras, devkit e blocos condicionais.

Nenhum dump, XAM, keyvault, CPUKey, credencial ou arquivo de console deve ser
adicionado ao Git. Os binarios privados continuam fora deste repositorio.

6. So depois: teste GIP minimo, um controle, sem rumble/UI/reset, seguido por

7. Testes no console exigem uma etapa explicitamente combinada com o usuario.
   Nao configurar autoboot nesta pesquisa. Usar HDD/USB, nunca OnBoardMU/Flash.

## Riscos e limites

Um plugin nao precisa gravar NAND para modificar codigo do kernel **em RAM**.
Endereco errado, uso incorreto de DPC/IRQL, callback ou transferencias USB
podem travar o console, causar reinicializacao, corromper dados em uso ou
provocar um ciclo de falha de boot se carregado automaticamente. Nao e risco
zero por estar em HDD/USB. Manter um caminho para iniciar sem o plugin.

O upstream documenta no fonte um custo de recursos por desconexao em um dos
caminhos de remocao USB. O port precisa testar reconexoes, nao apenas provar
que um botao responde uma vez. Nenhum prazo ou sucesso esta garantido.

Esta etapa nao conectou ao Xbox, nao instalou plugins, nao alterou launch.ini,
nao mexeu no pendrive, nao acessou CPUKey e nao gravou NAND/eMMC.
